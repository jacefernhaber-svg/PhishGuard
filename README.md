# PhishGuard 2.0

PhishGuard is an educational cybersecurity website
built using Python and Streamlit.

## Features
- Phishing message scanner
- URL structure inspector
- Phishing awareness quiz
- Rule-based risk scoring
- Detection evaluation dashboard

## Purpose
Help users recognize common phishing warning signs
and understand online security threats.

## Limitations
PhishGuard is an educational project.
Its results cannot guarantee that a message
or link is safe.
